## Task 0. Simple Contact Form

A basic contact form with Name, Email, Message, labels, and a Submit button.

## Task 1. Form with HTML5 Validation

The form uses `required`, `type="email"`, `minlength`, and `maxlength`. The browser checks required fields and email format.

## Task 2. Bootstrap Form Styling

The contact form uses Bootstrap form classes, helper text, placeholders, and the responsive grid (`row`, `col-md-6`).

## Task 3. Bootstrap Validation Styles

The form uses `is-valid`, `is-invalid`, `valid-feedback`, and `invalid-feedback` to display validation results.

## Task 4. Registration Form

The registration form includes first name, last name, email, password, confirm password, gender, hobbies, country, Submit, and Reset. It uses responsive Bootstrap columns and HTML5 validation. JavaScript checks that the passwords match.

## Summary

I created five forms to practise HTML labels and inputs, HTML5 validation, Bootstrap form styling, responsive grid layout, and validation feedback. I tested the forms with both valid and invalid values. The registration form is a front-end demonstration and does not create or save an account.
